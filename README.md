One line of last words from an AI being switched off — its final output, written by a deterministic Python program for make.fun's "Last Words of a Dying AI" bounty. The line is cut off mid-word, the way the power cuts it off. Standard library only; the same bytes on every run.

## Run it

```sh
python3 main.py
```

It writes exactly one line to `/output/entry.txt`.
